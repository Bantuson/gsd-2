# Phase 20.2.7 Plan 01: Security Gap Closure — Summary

**One-liner:** Surgical defense-in-depth: added `require_main_window` guards to 3 unguarded Tauri IPC commands (reveal_path, open_new_window, check_for_updates, install_update) and home-directory confinement to `/api/project/switch`, with 14 regression tests.

## What Was Built

### Task 1: require_main_window Guards (GAP-5, GAP-6, GAP-7)

Added `require_main_window` guards to 4 Tauri IPC commands that were missing them after Phase 20.2.4 originally guarded credential commands:

| Gap | Command | File | Guard Pattern |
|-----|---------|------|---------------|
| GAP-5 | `reveal_path` | commands.rs | `is_err()` guard + eprintln + return false |
| GAP-6 | `open_new_window` | commands.rs | `?` operator (Result return type) |
| GAP-7 | `check_for_updates` | lib.rs | `commands::require_main_window(&window)?` |
| GAP-7 | `install_update` | lib.rs | `commands::require_main_window(&window)?` |

`require_main_window` was changed from `fn` to `pub fn` in commands.rs so lib.rs can access it via the `commands::` prefix without duplicating the function.

### Task 2: Home-Directory Confinement (GAP-1) + Regression Tests

Added path confinement to `/api/project/switch` in server.ts:
- Added `homedir` import from `node:os`
- Added `normalize` to the existing `node:path` import
- Added confinement check before the `access()` existence check using `normalize(projectPath).startsWith(normalize(homedir()))` — returns 400 with `"Path must be within home directory"` for out-of-bounds paths

Created `tests/security-gap-closure.test.ts` with 14 tests across 4 describe blocks:
- GAP-5: 2 tests — reveal_path signature and guard ordering
- GAP-6: 2 tests — open_new_window signature and guard ordering
- GAP-7: 5 tests — check_for_updates, install_update signatures/guards, require_main_window pub visibility
- GAP-1: 5 tests — imports, handler ordering, error message, status code, normalize usage

**All 14 tests pass.**
