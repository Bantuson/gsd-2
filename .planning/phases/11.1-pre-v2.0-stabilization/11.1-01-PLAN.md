<objective>
Wire the config bridge so that config.json values for skip_permissions and worktree_enabled
actually affect the server at session-creation time. Also harden the server against network
exposure by binding the WebSocket to 127.0.0.1 and restricting CORS to the expected origin.

Purpose: The Settings UI toggles for skip_permissions and worktree_enabled are currently dead —
they write to config.json but the server never reads them. This plan closes that gap and removes
the two security issues (wildcard CORS, all-interfaces WS bind) documented in CONCERNS.md.

Output: Four modified server-side TypeScript files; all three SC-1/SC-2/SC-3 automated tests
green.
</objective>
