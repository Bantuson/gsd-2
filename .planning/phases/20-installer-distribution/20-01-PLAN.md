  <name>Task 1: GitHub Actions release workflow</name>
  <files>.github/workflows/release.yml</files>
  <action>
    Create `.github/workflows/release.yml` with the following structure:

    **Trigger:**
    ```yaml
    on:
      push:
        branches: ['release/*']
      workflow_dispatch:
    ```

    **Permissions:**
    ```yaml
    permissions:
      contents: write   # needed to create GitHub Release
    ```

    **Matrix strategy:**
    ```yaml
    strategy:
      matrix:
        include:
          - platform: macos-latest
            args: '--target universal-apple-darwin'
          - platform: windows-latest
            args: ''
          - platform: ubuntu-22.04
            args: ''
    ```

    **Steps (all platforms):**
    1. `actions/checkout@v4`
    2. `dtolnay/rust-toolchain@stable` with targets for universal macOS: add `aarch64-apple-darwin,x86_64-apple-darwin` on macOS runner
    3. `Swatinem/rust-cache@v2` to cache Cargo dependencies between runs
    4. `actions/setup-node@v4` with node-version 20
    5. Install Bun: `curl -fsSL https://bun.sh/install | bash && echo "$HOME/.bun/bin" >> $GITHUB_PATH` (Linux/macOS), or `irm bun.sh/install.ps1 | iex` (Windows, use `shell: pwsh`)
    6. `bun install` at repo root
    7. `bun run --cwd packages/mission-control build` (front-end bundle step, mirrors beforeBuildCommand)
    8. **macOS signing setup**: import Apple Developer ID certificate from `APPLE_CERTIFICATE` secret using the tauri-action import-cert pattern — base64-decode to keychain
    9. `tauri-apps/tauri-action@v0` with:
       - `tagName: ${{ github.ref_name }}`
       - `releaseName: 'GSD Mission Control ${{ github.ref_name }}'`
       - `releaseBody: 'See CHANGELOG.md for details.'`
       - `releaseDraft: true`
       - `prerelease: false`
       - `args: ${{ matrix.args }}`

    **Secrets referenced (set these as GitHub Actions secrets in repo settings):**
    - `APPLE_CERTIFICATE` — base64-encoded Apple Developer ID .p12 certificate
    - `APPLE_CERTIFICATE_PASSWORD` — .p12 export password
    - `APPLE_SIGNING_IDENTITY` — e.g. "Developer ID Application: Your Name (TEAMID)"
    - `APPLE_ID` — Apple ID email for notarization
    - `APPLE_PASSWORD` — app-specific password for notarization
    - `TAURI_SIGNING_PRIVATE_KEY` — ed25519 private key for Tauri updater (also used in Plan 02)
    - `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — passphrase for the above
    - `GITHUB_TOKEN` — automatic, no setup required

    **Windows signing (self-signed):**
    - Do NOT add WINDOWS_CERTIFICATE setup — self-signed is the default when no certificate is supplied to tauri-action. This is acceptable for v2.0 per the user decision.

    **Linux GPG signing of AppImage:**
    - Add a step after tauri-action: import GPG key from `GPG_PRIVATE_KEY` secret and run `gpg --detach-sign --armor dist/*.AppImage` in the ubuntu job. Gate with `if: matrix.platform == 'ubuntu-22.04'`.

    **Artifact note:** tauri-action@v0 automatically uploads artifacts to the draft release; no manual upload step needed.
