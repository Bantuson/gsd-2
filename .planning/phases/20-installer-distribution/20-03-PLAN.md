<task type="auto">
  <name>Task 2: GitHub Pages deployment workflow</name>
  <files>.github/workflows/pages.yml</files>
  <action>
    Create `.github/workflows/pages.yml` to deploy the `docs/` directory to GitHub Pages on every push to `main`.

    ```yaml
    name: Deploy landing page to GitHub Pages

    on:
      push:
        branches: [main]
        paths: ['docs/**']
      workflow_dispatch:

    permissions:
      contents: read
      pages: write
      id-token: write

    concurrency:
      group: pages
      cancel-in-progress: false

    jobs:
      deploy:
        runs-on: ubuntu-latest
        environment:
          name: github-pages
          url: ${{ steps.deploy.outputs.page_url }}
        steps:
          - uses: actions/checkout@v4

          - name: Setup Pages
            uses: actions/configure-pages@v5

          - name: Upload artifact
            uses: actions/upload-pages-artifact@v3
            with:
              path: docs/

          - name: Deploy to GitHub Pages
            id: deploy
            uses: actions/deploy-pages@v4
    ```

    **Setup required (user action, not Claude):** In the GitHub repo settings, enable GitHub Pages with Source = "GitHub Actions". This is a one-time click in the repo settings UI — Claude cannot do this programmatically.

    Note for executor: Add this to `user_setup` — the executor will surface it as a checkpoint instruction, not a task blocker.
  </action>
