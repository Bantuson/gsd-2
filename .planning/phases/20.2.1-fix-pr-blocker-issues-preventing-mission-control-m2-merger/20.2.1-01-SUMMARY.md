# Phase 20.2.1 Plan 01: IPC Security Guards Summary

Hardened Tauri IPC commands in commands.rs with URL scheme validation, absolute path validation, and a static credential key allowlist. Blocks WebView-initiated attacks that could open arbitrary URL schemes or probe arbitrary OS keychain entries.

## What Was Built

### commands.rs changes

1. **ALLOWED_CREDENTIAL_KEYS** — static const slice of 5 permitted keychain key names:
   - `anthropic_api_key`, `github_token`, `openrouter_api_key`, `claude_access_token`, `claude_refresh_token`

2. **open_external** — rejects any URL that does not start with `https://` or `http://` (blocks `javascript:`, `file://`, `gsd://` etc.)

3. **reveal_path** — rejects relative paths using `std::path::Path::new(&path).is_absolute()`

4. **get_credential / set_credential / delete_credential** — each validates key against `ALLOWED_CREDENTIAL_KEYS` before touching the OS keychain

### security-commands.test.ts

11 source-text tests using the `readFileSync` + `toContain` pattern:
- 2 tests for `open_external` URL scheme guard (B2)
- 2 tests for `reveal_path` path validation (B2)
- 7 tests for credential key allowlist presence and ordering (B3)
