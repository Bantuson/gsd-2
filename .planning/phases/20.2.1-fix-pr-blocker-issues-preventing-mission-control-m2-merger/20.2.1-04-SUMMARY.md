## What Was Built

### B6: Defensive CORS Header Reconstruction (server.ts)

The `addCorsHeaders` function was rewritten from the direct mutation pattern to a defensive reconstruction pattern:

- Before: `response.headers.set(...)` (mutates headers — fails on frozen Response objects)
- After: `new Headers(response.headers)` + `new Response(response.body, { status: response.status, headers })`

CORS origin remains `http://127.0.0.1:${HTTP_PORT}` (correct dynamic port, not hardcoded `localhost:4000`).

### B4: no_project_loaded Gate (pipeline.ts)

Four changes to implement the project selection gate:

1. `let projectSelected = false` — closure flag initialized before any session/WS setup
2. `onClientConnect` emits `{ type: "no_project_loaded" }` when `!projectSelected`
3. `onChatMessage` returns early with `chat_error: "No project selected. Open a project first."` when `!projectSelected`
4. `switchProject` sets `projectSelected = true` after resolving new paths

### Test Coverage
