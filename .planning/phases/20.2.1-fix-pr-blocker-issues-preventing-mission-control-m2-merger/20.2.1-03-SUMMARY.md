## User Setup Required

**TAURI_SIGNING_PRIVATE_KEY** must be added to GitHub Actions secrets by a repo maintainer:

1. Read the private key: `cat ~/.tauri/gsd-mc.key` (on the machine where Task 1 was run)
2. Go to GitHub repo Settings -> Secrets and variables -> Actions
3. Create secret `TAURI_SIGNING_PRIVATE_KEY` with the full private key contents
4. Verify the secret name matches `release.yml`: `TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}`

Until this secret is in place, `tauri build --ci` in the release workflow will fail at the updater signing step.
