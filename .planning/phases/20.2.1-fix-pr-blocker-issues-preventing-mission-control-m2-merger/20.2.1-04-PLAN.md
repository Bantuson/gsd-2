```typescript
function addCorsHeaders(response: Response): Response {
  response.headers.set("Access-Control-Allow-Origin", `http://127.0.0.1:${HTTP_PORT}`);
  response.headers.set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS");

```

Change TO:
```typescript
function addCorsHeaders(response: Response): Response {
  const headers = new Headers(response.headers);
  headers.set("Access-Control-Allow-Origin", `http://127.0.0.1:${HTTP_PORT}`);
  headers.set("Access-Control-Allow-Methods", "GET, POST, PUT, DELETE, OPTIONS");
  headers.set("Access-Control-Allow-Headers", "Content-Type, X-Window-Id");
  return new Response(response.body, { status: response.status, headers });
}
```

This creates a fresh Response with copied headers, safe against frozen Response objects in future Bun versions.

Do NOT change:
- The CORS origin value (keep `http://127.0.0.1:${HTTP_PORT}`)
- The allowed methods or headers lists
- Any other part of server.ts
