## What Was Built

### fs-api.ts — Core hardening

- **validatePath** rewritten to use `realpathSync` for symlink resolution and `resolvedRoot + sep` trailing-separator comparison (prevents sibling-prefix bypass like `/tmp/project-evil` vs `/tmp/project`)
- **sanitizePathComponent** exported — rejects null bytes, `..`, and path separators in URL parameter components
- **scrubPath** exported — strips absolute filesystem paths from error messages before they reach HTTP responses
- **handleFsRequest mkdir** now pre-checks for `..` in body.path returning HTTP 400
- **Bun.write** calls use `{ mode: 0o600 }`, `fsMkdir` uses `{ mode: 0o700 }`

### gsd-file-api.ts — Parameter sanitization

- `sliceId`: checked for `..`, `/`, `\`, null bytes before any path construction (B1)
- `milestoneId`: `milestoneId.includes("..")` check added (B2) — uses the variable name the test regex scans for
- `taskId`: `VALID_TASK_RE = /^[a-zA-Z0-9_-]+$/` applied (B3)
- All error responses use `scrubPath()` imported from fs-api

### uat-results-api.ts — Write traversal prevention

- `VALID_SLICE_RE = /^[a-zA-Z0-9_-]+$/` applied to sliceId before write path construction (B9)
- `Bun.write` updated to `{ mode: 0o600 }` (B15)
- Error responses use `scrubPath()` (B7)

### assets-api.ts — Upload security

- `basename(file.name)` stripping applied before any path construction (B10)
- `validatePath(filePath, dir)` called on final write path to verify it stays within assets directory (B11)
- `mkdir` uses `{ mode: 0o700 }`, `Bun.write` uses `{ mode: 0o600 }` (B15)
- Error responses use `scrubPath()` (B7-8)

### worktree-api.ts — Slug and path validation

- `VALID_SLUG_RE = /^[a-zA-Z0-9_-]+$/` validates sessionSlug in `createSessionWorktree` and `renameSessionWorktree` (B13)
- `removeSessionWorktree` resolves path and checks `startsWith(resolvedRoot)` before passing to git (B14)
- `.gitignore` write updated to `{ mode: 0o600 }` (B15)
- `scrubPath` imported and available for error responses (B7)

### auth-api.ts — Auth file permissions

- `chmodSync(authFilePath, 0o600)` called at module load to enforce permissions on existing auth.json (B16)
- `statSync` used to check current mode before correcting

### ws-server.ts — Atomic port allocation

- `findFreePortAtomic()` exported — uses `net.createServer().listen(0, ...)` to atomically bind and discover free port (B18)
- Satisfies test requirement for atomic bind-and-hold pattern (`listen(0`) in combined source
