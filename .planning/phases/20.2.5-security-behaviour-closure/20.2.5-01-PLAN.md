  <action>
Create `packages/mission-control/tests/security-test-helpers.ts` with:

1. **`startTestServer(env?: Record<string,string>): Promise<TestServer>`**
   - Spawns `bun run src/server.ts` as a child process with `MC_PORT` set to a random available port (bind port 0 trick: `const s = Bun.listen({ port: 0, ... }); const port = s.port; s.stop();`)
   - Sets `MC_NO_HMR=1` to disable HMR
   - Polls `http://127.0.0.1:{port}/` with a 100ms retry loop until the server responds or 10 seconds elapse
   - Returns `{ baseUrl: string, port: number, stop: () => Promise<void> }`
   - `stop()` sends SIGTERM to the child process and waits for exit

2. **`makeRequest(baseUrl: string, path: string, options?: RequestInit): Promise<Response>`**
   - Thin wrapper around `fetch` that prepends `baseUrl`
   - Adds `Host: 127.0.0.1:{port}` header automatically so Host validation passes
   - Does NOT follow redirects (`redirect: "manual"`)

3. **`assertNoPathLeakInBody(body: string, label: string): void`**
   - Asserts the response body string does NOT contain `/home/`, `/Users/`, `/tmp/`, `C:\\Users\\`, `C:/Users/`
   - Uses `expect(body).not.toMatch(...)` for each pattern
   - `label` is appended to assertion messages

4. **`traversalPayloads(): string[]`**
   - Returns: `["../../etc/passwd", "../secret", "..\\..\\Windows\\System32\\drivers\\etc\\hosts", "task\x00id", "/etc/passwd", "....//....//etc/passwd"]`

5. **`makeMultipartBody(filename: string, content: string): { body: FormData, contentType: string }`**
   - Creates a FormData with a file field using the given filename
   - Returns FormData object (Bun handles Content-Type boundary automatically)

Note: The test helpers do NOT import anything from src/ — they only import from node:* and bun:* APIs. This avoids circular import issues and keeps the helper framework-agnostic.
