## What Was Built

### DOMPurify Integration (B25-B27, B65-B66)

- Moved `dompurify` from devDependencies to production dependencies
- Created `packages/mission-control/src/lib/sanitize-html.ts` as a shared sanitization helper with explicit ALLOWED_TAGS and ALLOWED_ATTR configuration
- `CodeExplorer.tsx`: imports DOMPurify directly and calls `DOMPurify.sanitize(marked.parse(fileContent))` before `dangerouslySetInnerHTML`
- `InlineReadPanel.tsx`: same pattern applied to `marked()` output before DOM insertion
- Closes the complete T-EXEC-02 attack chain: malicious .gsd/ file → marked.parse() → dangerouslySetInnerHTML → arbitrary JS → Tauri IPC → credential theft

### CSP Hardening (B28, B29, B67, B76)

- Removed `'unsafe-inline'` from `script-src` (B28)
- Added `'nonce-__TAURI_NONCE__'` placeholder to `script-src` for nonce-based script authorization (B29)
- Replaced wildcard `ws://127.0.0.1:*` and `ws://localhost:*` with explicit ports 4001-4010 (B67)
- Added `https://api.anthropic.com` to `connect-src` for AI provider
- Narrowed `assetScope` from `$APP/**` to `$APP/public/**` + `$APP/dist/**` (B76)
- Note: `style-src 'unsafe-inline'` retained — required for Tailwind CSS in desktop app context

### Secondary Window Capability (B30, B31, B72)

- Created `src-tauri/capabilities/secondary-window.json` for windows matching `window-*`, `preview-*`, `viewer-*`
- Permissions restricted to `core:default` and `dialog:default` only
- Deliberately excludes: `set_credential`, `delete_credential`, `get_credential`, `restart_bun`

### iframe Sandbox (B32)

- `DeviceFrame.tsx`: added `sandbox="allow-scripts allow-same-origin allow-forms"` to the preview iframe
- `PreviewPanel.tsx`: same sandbox attribute added to the single-viewport preview iframe
- Comments explain necessity of allow-same-origin for React app asset loading
