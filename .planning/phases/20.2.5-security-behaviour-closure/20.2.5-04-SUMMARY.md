# Phase 20.2.5 Plan 04: Harden validatePath and atomic freePort Summary

## One-Liner

Replaced resolve()+startsWith with realpathSync()+path.sep in validatePath (B4/B5/B6/B17) and replaced kill-then-sleep freePort with bind-probe pattern returning confirmed-free port (B18).

## What Was Built

### Task 1: Hardened validatePath (fs-api.ts)

The validatePath function was completely rewritten with three security improvements:

1. Null byte rejection - requestedPath.includes null byte check before any path resolution.

2. realpathSync for symlink resolution - replaces path.resolve() (does NOT follow symlinks) with realpathSync(). When /workspace/link/passwd is passed where link -> /tmp, resolve() returns /workspace/link/passwd (appears inside root) but realpathSync() returns /tmp/passwd (correctly outside root). Fixes B6 and B17.

3. path.sep guard for sibling prefix bypass - compares against resolvedRoot + path.sep. Without sep: /workspace-evil starts with /workspace (false positive). With sep: /workspace-evil does NOT start with /workspace/ (correct rejection). Fixes B4 and B5.

Additional changes:
- All HTTP error responses return generic messages (Invalid path, Path not allowed, Internal server error) - never err.message
- Added scrubPaths() helper for server-side console logging (not used in responses)
- Backward compatibility: validatePath(path) without a root still rejects .. segments

### Task 2: Atomic freePort (kill-port.ts)

The freePort function was rewritten to return Promise<number> (was Promise<void>) with atomic bind-probe pattern:

1. Kill existing holder - same execFile-based kill logic (already secure from B22)
2. Verify free with probe bind - checkPortFree(port) attempts to briefly bind the port
3. Up to 3 retry attempts with 50ms backoff if kill was slow
4. Ephemeral fallback - if still busy, getEphemeralPort() binds port 0 for OS-assigned free port
5. freePort(0) - directly uses getEphemeralPort() for any-port requests

server.ts updated to use returned port in registerWindow (actualWsPort = await freePort(wsPort)).
