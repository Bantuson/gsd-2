Read worktree-api.ts. Add input validation at the entry points for routes that use sessionSlug.

**Add VALID_SLUG_RE constant near the top of the file:**
```typescript
/** Only allow alphanumeric characters, hyphens, and underscores in session slugs. */
const VALID_SLUG_RE = /^[a-zA-Z0-9_-]+$/;

function validateSlug(slug: string): string {
  if (!slug || typeof slug !== "string") {
    throw new Error("Invalid session slug");
  }
  if (slug.includes("\x00") || slug.includes("..") || slug.includes("/") || slug.includes("\\")) {
    throw new Error("Invalid session slug");
  }
  if (!VALID_SLUG_RE.test(slug)) {
    throw new Error("Invalid session slug");
  }
  return slug;
}
```

**Apply to every route that uses sessionSlug:**
```typescript
// At the start of each route handler:
let validSlug: string;
try {
  validSlug = validateSlug(sessionSlug);
} catch {
  return Response.json({ error: "Invalid session slug" }, { status: 400 });
}
```

**Fix removeSessionWorktree (B14) — add path containment check before rm -rf:**
Find the removeSessionWorktree function. Before the git worktree remove or rm -rf call, add:
```typescript
import { realpathSync } from "node:fs";
import path from "node:path";

// Verify the resolved worktree path is within the repository root
let resolvedWorktreePath: string;
let resolvedRepoRoot: string;
try {
  resolvedRepoRoot = realpathSync(repoRoot);
  resolvedWorktreePath = realpathSync(worktreePath);
} catch {
  return Response.json({ error: "Invalid worktree path" }, { status: 400 });
}

if (!resolvedWorktreePath.startsWith(resolvedRepoRoot + path.sep)) {
  console.error("[worktree-api] Blocked rm -rf outside repo root:", resolvedWorktreePath);
  return Response.json({ error: "Invalid worktree path" }, { status: 400 });
}
```

This check must run before ANY deletion command is issued. If the path check fails, return 400
