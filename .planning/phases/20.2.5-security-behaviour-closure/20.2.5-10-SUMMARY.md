## Decisions Made

- Added `/api/auth/session` as a new unauthenticated endpoint to enable the B43 session cap test. The existing `/api/auth/login` starts real OAuth flows; a lightweight session slot endpoint avoids triggering external auth providers during tests.
- Rate limiter uses the `x-real-ip` header, falling back to `127.0.0.1`. Since the server binds to loopback only, all real requests will be from 127.0.0.1, making the rate limit effectively per-server rather than per-client. This is intentional — the cap protects against local DoS from the app itself or malicious code running locally.
- B59 URL length check placed before the `gsd://oauth/callback` prefix check — any overly long URL is rejected regardless of scheme.
