<objective>
Implement per-launch secret token authentication for all HTTP and WebSocket endpoints.

This is the most significant feature addition in this phase. The server generates a single
`crypto.randomUUID()` token at startup. The token is passed to the frontend via a startup
handshake mechanism. All subsequent HTTP requests must include `Authorization: Bearer <token>`.
All WebSocket upgrade requests must include the token.

This closes the T-AUTH-01 attack surface: any local process or DNS-rebinding attacker can no
longer call any API without possessing the per-launch token.

Purpose: Implement per-launch token auth — the single most impactful security improvement in this phase.
Output: Token-authenticated HTTP + WS server, CORS preflight fix, Origin validation.
</objective>

```typescript
 * T-AUTH-01 B50/B53: Per-launch secret token generated using crypto.randomUUID().
 * This token must be presented as Authorization: Bearer <token> on all /api/* requests.
 * The token is exposed ONCE via /api/auth/startup-token for the Tauri frontend to retrieve.
 * After first retrieval, it is not exposed again.

export const LAUNCH_TOKEN = crypto.randomUUID();

/** Whether the startup token has been retrieved. After retrieval, the endpoint is locked. */
let startupTokenRetrieved = false;
```

**Step 2 — Add a startup token endpoint (for Tauri frontend bootstrap):**
Add a special route that can ONLY be called from a Tauri/file:// origin and only once:
```typescript
// T-AUTH-01: Single-use startup token endpoint
// Called by the Tauri frontend immediately after WebView loads
// Locked after first successful retrieval
if (pathname === "/api/auth/startup-token" && req.method === "GET") {
  const origin = req.headers.get("origin") ?? "";
  if (!origin.startsWith("tauri://") && !origin.startsWith("file://") && origin !== "") {
    return new Response(JSON.stringify({ error: "Forbidden" }), { status: 403 });
  }
  if (startupTokenRetrieved) {
    return new Response(JSON.stringify({ error: "Token already retrieved" }), { status: 403 });
  }
  startupTokenRetrieved = true;
  return new Response(JSON.stringify({ token: LAUNCH_TOKEN }), {
    status: 200,
    headers: { "Content-Type": "application/json" },
  });
}
```

**Step 3 — Add CORS preflight handler BEFORE all route handlers (B56):**

```typescript
if (req.method === "OPTIONS") {

  const allowedOrigins = new Set(["tauri://localhost", "file://"]);
```

**Step 4 — Add token validation middleware for all /api/* routes (B50, B55):**
Add immediately after the CORS preflight handler:
```typescript
// T-AUTH-01 B50: Token validation for all API routes
// T-AUTH-01 B55: Origin validation for all API routes
if (pathname.startsWith("/api/") && pathname !== "/api/auth/startup-token") {
  const authHeader = req.headers.get("authorization") ?? "";
  const providedToken = authHeader.startsWith("Bearer ") ? authHeader.slice(7) : "";

  // B55: Validate Origin — must be tauri://, file://, or absent (same-origin IPC)
  const origin = req.headers.get("origin") ?? "";
  const originOk = origin === "" || origin.startsWith("tauri://") || origin.startsWith("file://");

  // B50: Validate token
  const tokenOk = providedToken === LAUNCH_TOKEN;

  if (!originOk) {
    return new Response(JSON.stringify({ error: "Forbidden" }), {
      status: 403,
      headers: { "Content-Type": "application/json" },
    });
  }

  if (!tokenOk) {
    return new Response(JSON.stringify({ error: "Unauthorized" }), {
      status: 401,
      headers: { "Content-Type": "application/json" },
    });
  }
}
```

IMPORTANT: The `/api/auth/startup-token` endpoint MUST be excluded from token validation
(it is the bootstrap endpoint that provides the token). Also exclude `OPTIONS` requests
(already handled above). All other `/api/*` routes require the token.

Remove the comment block starting with "SECURITY NOTE — Intentional: No authentication" —
that design decision is now reversed.

Add a token storage mechanism:
```typescript
// T-AUTH-01: Per-launch token retrieved from server at startup
let launchToken: string | null = null;

export async function retrieveLaunchToken(): Promise<string> {
  if (launchToken) return launchToken;

  const res = await fetch("http://127.0.0.1:4200/api/auth/startup-token");
  if (!res.ok) throw new Error("Failed to retrieve launch token");
  const { token } = await res.json();
  launchToken = token;
  return token;
}

export function getLaunchToken(): string | null {
  return launchToken;
}
```

Update the fetch monkey-patch in window-identity.ts to automatically include the

```typescript
const originalFetch = window.fetch;
window.fetch = async function(input, init) {
  const token = getLaunchToken();
  if (token && typeof input === "string" && input.includes("/api/")) {
    init = init ?? {};
    // B75: Handle all three header forms correctly
    const existingHeaders = init.headers;
    let headersObj: Record<string, string> = {};

    if (existingHeaders instanceof Headers) {
      existingHeaders.forEach((v, k) => { headersObj[k] = v; });
    } else if (Array.isArray(existingHeaders)) {
      for (const [k, v] of existingHeaders) { headersObj[k] = v; }
    } else if (existingHeaders) {
      headersObj = { ...existingHeaders as Record<string, string> };
    }

    headersObj["Authorization"] = `Bearer ${token}`;
    init.headers = headersObj;
  }
  return originalFetch.call(this, input, init);
};
```
