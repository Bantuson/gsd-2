## NEXT TASK: Fix adapter to show tool calls in streaming output

**Problem**: In `claude-process.ts` sendMessage() parser callback, ALL tool-related events are silently dropped:
- `tool_execution_start` — what tool is running + command
- `tool_execution_update` — streaming tool output (cumulative)
- `tool_execution_end` — tool finished
- `message_update.toolcall_*` — tool arguments assembling

Result: Any GSD operation using bash/file tools shows NOTHING in the chat. User sees blank response.

**Fix needed** in `sendMessage()` parser callback (claude-process.ts lines ~130-177):

Add these handlers (insert before the `// Pass through GSD-specific events` fallthrough):

```typescript
// Helper — declare inside sendMessage() before createNdjsonParser call:
let lastToolOutputLength = 0;

// tool_execution_start → show tool name + command
if (rawType === "tool_execution_start") {
  lastToolOutputLength = 0;
  const toolName = raw.toolName as string;
  const args = raw.args as Record<string, unknown> | undefined;
  let header = `\n[${toolName}]`;
  if (toolName === "bash" && args?.command) {
    header += `\n$ ${String(args.command)}`;
  }
  const emitText = (text: string) => emit({
    type: "stream_event",
    event: { type: "content_block_delta", delta: { type: "text_delta", text } },
  } as StreamEvent);
  emitText(header + "\n");
  return;
}

// tool_execution_update → stream delta of cumulative output
if (rawType === "tool_execution_update") {
  const partialResult = raw.partialResult as { content?: Array<{type: string; text: string}> } | undefined;
  const currentText = partialResult?.content?.[0]?.text ?? "";
  const delta = currentText.slice(lastToolOutputLength);
  lastToolOutputLength = currentText.length;
  if (delta) emit({
    type: "stream_event",
    event: { type: "content_block_delta", delta: { type: "text_delta", text: delta } },
  } as StreamEvent);
  return;
}

// tool_execution_end → reset tracking
if (rawType === "tool_execution_end") {
  lastToolOutputLength = 0;
  emit({
    type: "stream_event",
    event: { type: "content_block_delta", delta: { type: "text_delta", text: "\n" } },
  } as StreamEvent);
  return;
}
```

NOTE: `lastToolOutputLength` must be declared inside `sendMessage()` body before `createNdjsonParser` call (closure variable).
