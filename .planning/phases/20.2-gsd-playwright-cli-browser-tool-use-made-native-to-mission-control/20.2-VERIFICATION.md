## Human Verification Required

### 1. Headless mode suppresses external Chromium window

**Test:** Start a GSD session from Mission Control in a project that invokes browser tools (e.g., ask GSD to navigate to google.com or take a screenshot). Observe the desktop for any Chromium/Chrome window appearing.
**Expected:** No external browser window opens; all browser activity runs silently in the background
**Why human:** Window presence/absence cannot be detected via static code analysis. Requires a live GSD session with actual Playwright execution.

### 2. Screenshot appears in preview panel during browser activity

**Test:** While the above session is running and GSD uses `browser_navigate` or `browser_screenshot`, watch the Mission Control preview panel.
**Expected:** Preview panel opens automatically (if not already open), shows an amber "Browser Agent" badge in the header, displays a URL bar with the current page URL, and renders the screenshot as a full-width image below the URL bar.
**Why human:** Requires live WebSocket message flow with real base64 screenshot data from Playwright. Unit tests stub the WS layer and do not exercise the full pipeline.

### 3. 10-second auto-clear returns to iframe mode

**Test:** After browser activity stops (GSD finishes browser tool calls), wait 10 seconds while watching the preview panel.
**Expected:** After 10 seconds of no new browser_state_update messages, the "Browser Agent" badge disappears and the panel reverts to showing the iframe dev server (or empty iframe state if no dev server is running).
**Why human:** Timer expiry behavior requires real elapsed time in a live React render cycle.

### 4. Port:0 guard prevents invalid server entry

**Test:** Trigger browser activity (which sends `preview_open` with `port: 0`). Check the server/port list in the preview panel header.
**Expected:** No "Port 0" or invalid entry appears in the port selector; only legitimate dev servers are listed.
**Why human:** Requires observing the UI port list in a live state where both browser activity and the guard logic are active.
