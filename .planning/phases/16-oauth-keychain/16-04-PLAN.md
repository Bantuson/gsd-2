# Plan 16-04: Settings Provider Section + Tests + Human Verification

## Goal

Add the "Provider" section to `SettingsView` so users can see their active provider, connection status, and last-refreshed timestamp, and trigger a provider change. Write automated tests for the auth API layer. Finish with a human verification checkpoint.

## Tasks

<task id="16-04-01">
Add a "Provider" section to `packages/mission-control/src/components/views/SettingsView.tsx`.

Read the current `SettingsView.tsx` first — it uses a `Section` component with expand/collapse. The Provider section follows the same pattern.

**Import additions:**
```typescript
import { KeyRound, RefreshCw, Wifi, WifiOff } from "lucide-react";
import { getProviderStatus, changeProvider } from "@/auth/auth-api";
import type { ProviderStatus } from "@/auth/auth-api";
```

**Provider section state** (in the main `SettingsView` component):
```typescript
const [providerStatus, setProviderStatus] = useState<ProviderStatus | null>(null);
const [changingProvider, setChangingProvider] = useState(false);
```

On section open (or on mount — use `useEffect` with empty dep array), call `getProviderStatus()` and set `providerStatus`.

**Provider section content:**
```
Provider
─────────────────────────────────────────
Active provider:    [Anthropic / GitHub Copilot / OpenRouter / API Key]
Connection status:  ● Connected  (green)  |  ○ Expired  (red)
Last refreshed:     2026-03-13 at 14:32   (JetBrains Mono, slate-400)

[Change provider →]
```

- "Active provider": Share Tech Mono, white, provider display name (map from stored key: `anthropic` → "Anthropic (Claude Max)", `github-copilot` → "GitHub Copilot", `openrouter` → "OpenRouter", `api-key` → "API Key")
- "Connection status": green dot + "Connected" if `!is_expired && !expires_soon`; amber dot + "Expiring soon" if `expires_soon`; red dot + "Expired" if `is_expired`
- "Last refreshed": format the ISO string as human-readable local time. If null: "Never"
- "Change provider" button: ghost style, right-aligned. On click: call `changeProvider()`, then emit a window reload or navigate to picker. The cleanest approach: call `changeProvider()` then `window.location.reload()` — on reload, `useAuthGuard` will find no active_provider and show the picker automatically.
- Confirmation guard: before calling `changeProvider()`, set `changingProvider = true` and show an inline confirmation: "This will disconnect your current provider and show the provider picker. Continue? [Yes, change] [Cancel]"

**If `providerStatus === null`** (loading): show a skeleton row (use existing `PanelSkeleton` pattern).

**If `providerStatus.active_provider === null`**: show "No provider configured" with a "Set up provider →" link that triggers `window.location.reload()` (picker will show on next load if no provider in keychain, which is the case since we just confirmed it).

Insert this section as the FIRST section in `SettingsView` (before AI Model Settings), since it's the most critical configuration.

Section icon: `<KeyRound className="h-4 w-4" />` in the same style as other section icons.
</task>

<task id="16-04-02">
Create `packages/mission-control/tests/auth.test.ts`.

Test the auth API functions. Since these wrap Tauri IPC which isn't available in Bun test, use the non-Tauri fallback paths (which return safe defaults without calling `invoke`).

```typescript
import { describe, test, expect } from "bun:test";

// Import functions — in Bun test env, isTauri() returns false
// so all invoke calls are skipped, and safe fallbacks are returned.
// This validates that the module loads correctly and fallbacks work.

describe("auth-api non-Tauri fallbacks", () => {
  test("getActiveProvider returns null in non-Tauri env", async () => {
    const { getActiveProvider } = await import("../src/auth/auth-api");
    const result = await getActiveProvider();
    expect(result).toBeNull();
  });

  test("checkAndRefreshToken returns safe default in non-Tauri env", async () => {
    const { checkAndRefreshToken } = await import("../src/auth/auth-api");
    const result = await checkAndRefreshToken();
    expect(result.needs_reauth).toBe(false);
    expect(result.refreshed).toBe(false);
    expect(result.provider).toBeNull();
  });

  test("saveApiKey returns false in non-Tauri env", async () => {
    const { saveApiKey } = await import("../src/auth/auth-api");
    const result = await saveApiKey("openrouter", "test-key");
    expect(result).toBe(false);
  });
});

describe("ProviderPickerScreen renders", () => {
  // Use static source-text strategy (same as Phase 12-01 tests)
  // Read the file as string and assert key content

    const fs = await import("fs");
```
