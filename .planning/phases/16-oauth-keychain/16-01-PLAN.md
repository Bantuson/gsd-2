# Plan 16-01: Rust OAuth Backend

## Goal

Implement the Rust-side OAuth infrastructure: PKCE flow, token exchange, token storage, token refresh, and the `gsd://oauth/callback` URL scheme handler. Expose all operations as Tauri IPC commands.

## Context

Phase 15 (`commands.rs`) already implements `get_credential`, `set_credential`, `delete_credential`, `open_external`, and `open_folder_dialog`. Phase 15 also registered a stub `gsd://` URI scheme handler in `lib.rs`. This plan fills in the OAuth machinery and wires it to the scheme handler.

**Keychain key names (all under service `gsd-mission-control`):**
- `active_provider` — e.g., `"anthropic"`, `"github-copilot"`, `"openrouter"`, `"api-key"`
- `anthropic_access_token`
- `anthropic_refresh_token`
- `github_copilot_access_token`
- `{provider}_api_key` — for OpenRouter / direct key providers
- `{provider}_expires_at` — ISO 8601 string
- `{provider}_last_refreshed` — ISO 8601 string

**`~/.gsd/auth.json` format:**
```json
{
  "provider": "anthropic",
  "access_token": "...",
  "refresh_token": "...",
  "expires_at": "2026-03-13T18:00:00Z"
}
```

<task id="16-01-02">
Create `src-tauri/src/oauth.rs`.

This module provides:

**PKCE generation:**
```rust
pub struct PkceChallenge {
    pub code_verifier: String,
    pub code_challenge: String, // S256
}

pub fn generate_pkce() -> PkceChallenge
```
- Generate 32-byte random verifier (base64url-encoded)
- SHA-256 hash → base64url-encode → code_challenge

**OAuth URL builders:**
```rust
pub fn anthropic_auth_url(pkce: &PkceChallenge, state: &str) -> String
pub fn github_copilot_auth_url(pkce: &PkceChallenge, state: &str) -> String
```
- These return the provider authorization URLs with PKCE params and `redirect_uri=gsd://oauth/callback`
- For Anthropic: use Claude OAuth endpoint (placeholder URL — real URL configured via env or constants)
- For GitHub Copilot: use GitHub OAuth endpoint

**Token exchange:**
```rust
pub async fn exchange_code(
    provider: &str,
    code: &str,
    code_verifier: &str,
) -> Result<TokenResponse, String>
```
- POST to provider token endpoint with code + verifier
- Returns `TokenResponse { access_token, refresh_token, expires_in }`

**Token refresh:**
```rust
pub async fn refresh_token(provider: &str, refresh_token: &str) -> Result<TokenResponse, String>
```

**Auth.json writer:**
```rust
pub fn write_auth_json(
    provider: &str,
    access_token: &str,
    refresh_token: Option<&str>,
    expires_at: Option<&str>,
) -> Result<(), String>
```
- Writes to `~/.gsd/auth.json` (create dir if needed)
- JSON format as specified above

All functions use `eprintln!` for error logging, never panic.
</task>

<task id="16-01-03">
Add new Tauri IPC commands to `src-tauri/src/commands.rs`:

**`get_active_provider() -> Option<String>`**
- Calls `get_credential("active_provider")` logic directly
- Returns the stored provider string or None

**`start_oauth(provider: String) -> StartOAuthResult`**
- Generate PKCE pair
- Generate random state string (16 bytes, hex-encoded)
- Store `pkce_verifier_{state}` in keychain (keyed by state to handle concurrent flows)
- Call `open_external(auth_url)` — returns the auth URL to frontend too
- Return `{ auth_url: String, state: String }`

```rust
#[derive(serde::Serialize)]
pub struct StartOAuthResult {
    pub auth_url: String,
    pub state: String,
}
```

**`complete_oauth(provider: String, code: String, state: String) -> bool`**
- Retrieve `pkce_verifier_{state}` from keychain
- Call `oauth::exchange_code(provider, code, verifier)`
- On success: store access_token, refresh_token, expires_at, active_provider in keychain; call `oauth::write_auth_json`; delete verifier key
- Return true on success

**`save_api_key(provider: String, key: String) -> bool`**
- Store `{provider}_api_key` in keychain
- Store `"active_provider"` = provider in keychain
- Call `oauth::write_auth_json(provider, key, None, None)` — no expiry for static keys
- Return true on success

**`get_provider_status() -> ProviderStatus`**
```rust
#[derive(serde::Serialize)]
pub struct ProviderStatus {
    pub active_provider: Option<String>,
    pub last_refreshed: Option<String>,
    pub expires_at: Option<String>,
    pub is_expired: bool,
    pub expires_soon: bool, // within 5 minutes
}
```
- Read keychain for all relevant keys
- Compute `is_expired` and `expires_soon` from expires_at vs current time

**`change_provider() -> bool`**
- Delete keychain entries: `active_provider`, `anthropic_access_token`, `anthropic_refresh_token`, `github_copilot_access_token`, `anthropic_expires_at`, `github_copilot_expires_at`
- Delete `~/.gsd/auth.json` if it exists
- Return true

**`check_and_refresh_token() -> RefreshResult`**
```rust
#[derive(serde::Serialize)]
pub struct RefreshResult {
    pub needs_reauth: bool,
    pub refreshed: bool,
    pub provider: Option<String>,
}
```
- Get active_provider from keychain; if None return `{ needs_reauth: false, refreshed: false, provider: None }`
- Get expires_at; if within 5 minutes, attempt refresh
- On successful refresh: update keychain + auth.json, return `{ refreshed: true, ... }`
- On refresh failure: return `{ needs_reauth: true, ... }`
- If not expiring: return `{ needs_reauth: false, refreshed: false, provider }`
</task>

<task id="16-01-04">

2. Update `gsd://` URI scheme handler to parse OAuth callbacks:

```rust
.register_uri_scheme_protocol("gsd", |app, request| {
    let url = request.uri().to_string();
    if url.starts_with("gsd://oauth/callback") {
        // Parse code and state from query string
        // Emit "oauth-callback" event to frontend with { code, state }
        // Frontend calls complete_oauth IPC command
        use tauri::Emitter;
        let _ = app.emit("oauth-callback", parse_oauth_params(&url));
    }
    tauri::http::Response::builder()
        .status(200)
        .header("Content-Type", "text/html")
        .body(b"<html><body>Authentication complete. Return to GSD Mission Control.</body></html>".to_vec())
        .unwrap()
})
```

Where `parse_oauth_params` extracts `code` and `state` from the query string and returns a `serde_json::Value`.
