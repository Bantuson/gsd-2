# Plan 16-02: TypeScript Auth API Layer + Hooks

## Goal

Create the TypeScript bridge to all Rust OAuth commands, plus two hooks:
- `useAuthGuard` — determines on app load whether the provider picker must be shown
- `useTokenRefresh` — on app load, silently refreshes expiring tokens; surfaces re-auth state

These run in the browser context (Tauri webview). They use `window.__TAURI__.core.invoke` — same pattern as existing IPC calls in the project.

## Context

The existing code uses the pattern `import { invoke } from "@tauri-apps/api/core"` (or the global pattern). Check `packages/mission-control/src` for how other Tauri IPC calls are made. Follow the same import pattern. Note: the app also runs in browser (non-Tauri) mode for development — guard all `invoke` calls with an `isTauri()` helper.

This module wraps every Rust command from Plan 16-01. When not running in Tauri (browser dev mode), all functions return safe defaults.

```typescript
// Detect Tauri environment
function isTauri(): boolean {
  return typeof window !== "undefined" && "__TAURI__" in window;
}

async function invoke<T>(cmd: string, args?: Record<string, unknown>): Promise<T> {
  if (!isTauri()) throw new Error("Not running in Tauri");
  const { invoke: tauriInvoke } = await import("@tauri-apps/api/core");
  return tauriInvoke<T>(cmd, args);
}

export interface StartOAuthResult {
  auth_url: string;
  state: string;
}

export interface ProviderStatus {
  active_provider: string | null;
  last_refreshed: string | null;
  expires_at: string | null;
  is_expired: boolean;
  expires_soon: boolean;
}

export interface RefreshResult {
  needs_reauth: boolean;
  refreshed: boolean;
  provider: string | null;
}

export async function getActiveProvider(): Promise<string | null>
export async function startOAuth(provider: string): Promise<StartOAuthResult>
export async function completeOAuth(provider: string, code: string, state: string): Promise<boolean>
export async function saveApiKey(provider: string, key: string): Promise<boolean>
export async function getProviderStatus(): Promise<ProviderStatus>
export async function changeProvider(): Promise<boolean>
export async function checkAndRefreshToken(): Promise<RefreshResult>
```

Each function calls `invoke(commandName, args)` and returns the result. On error: log with `console.error("[auth-api]", e)` and return a safe fallback (null / false / default struct).

Non-Tauri fallback for `getActiveProvider`: return `null` (picker will show in dev, which is acceptable).
Non-Tauri fallback for `checkAndRefreshToken`: return `{ needs_reauth: false, refreshed: false, provider: null }`.

<task id="16-02-02">
Create `packages/mission-control/src/auth/useAuthGuard.ts`.

```typescript
import { useState, useEffect } from "react";
import { getActiveProvider } from "./auth-api";

export type AuthGuardState =
  | { status: "checking" }
  | { status: "authenticated"; provider: string }
  | { status: "needs_picker" };

export function useAuthGuard(): AuthGuardState {
  const [state, setState] = useState<AuthGuardState>({ status: "checking" });

  useEffect(() => {
    getActiveProvider().then((provider) => {
      if (provider) {
        setState({ status: "authenticated", provider });
      } else {
        setState({ status: "needs_picker" });
      }
    });
  }, []);

  return state;
}
```

This hook runs once on mount. The `"checking"` state is brief (keychain read). The consumer (App.tsx) renders a loading splash during `"checking"`, the provider picker during `"needs_picker"`, and the full AppShell during `"authenticated"`.

Export a companion `useAuthGuardDispatch` helper that returns a `setAuthenticated(provider: string) => void` function — called by the provider picker on successful auth to transition state without re-mounting App.

Actually, simpler: export `useAuthGuard` that returns `[state, setAuthenticated]` tuple where `setAuthenticated(provider)` updates the state to `{ status: "authenticated", provider }`.
</task>

<task id="16-02-03">
Create `packages/mission-control/src/auth/useTokenRefresh.ts`.

```typescript
import { useEffect, useState } from "react";
import { checkAndRefreshToken } from "./auth-api";
import type { RefreshResult } from "./auth-api";

export interface TokenRefreshState {
  checked: boolean;
  needsReauth: boolean;
  provider: string | null;
}

export function useTokenRefresh(): TokenRefreshState {
  const [state, setState] = useState<TokenRefreshState>({
    checked: false,
    needsReauth: false,
    provider: null,
  });

  useEffect(() => {
    checkAndRefreshToken().then((result: RefreshResult) => {
      setState({
        checked: true,
        needsReauth: result.needs_reauth,
        provider: result.provider,
      });
    });
  }, []);

  return state;
}
```

This hook is called from App.tsx (or the authenticated shell) after `useAuthGuard` confirms a provider is set. If `needsReauth` is true, App.tsx shows a re-auth prompt (the provider picker again, but with a `"Re-connect [Provider]"` heading instead of the first-launch heading).

Also: listen for Tauri events from Rust's `oauth-callback` emitter:

```typescript
// In useTokenRefresh or a separate useOAuthCallback hook:
import { listen } from "@tauri-apps/api/event";

// Call listen("oauth-callback", handler) and return unlisten on cleanup
```

Actually, put the `oauth-callback` event listener in `useAuthGuard` rather than `useTokenRefresh`, since it's the auth state that needs to update when OAuth completes. Document this clearly in a comment.

Update `useAuthGuard` to:
1. On mount: check keychain
2. Set up `listen("oauth-callback", ({ payload }) => { /* call completeOAuth, then setAuthenticated */ })` — unlisten on unmount

The handler receives `{ code, state }` from Rust, calls `completeOAuth(provider, code, state)`, and on success calls `setAuthenticated(provider)`.

To know which provider is currently in progress, `useAuthGuard` must track `pendingProvider: string | null` in state — set by the picker when it calls `startOAuth`.

Export `useAuthGuard` as:
```typescript
export function useAuthGuard(): {
  state: AuthGuardState;
  setAuthenticated: (provider: string) => void;
  setPendingProvider: (provider: string) => void;
  pendingProvider: string | null;
}
```
