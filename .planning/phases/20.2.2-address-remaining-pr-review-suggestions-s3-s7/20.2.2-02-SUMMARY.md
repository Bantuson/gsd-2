## What Was Done

### Task 1: S6 — releaseDraft: false (OTA Fix)

Changed `releaseDraft: true` to `releaseDraft: false` in `.github/workflows/release.yml` (line 107). GitHub Draft releases are excluded from the `releases/latest/download/latest.json` endpoint that the Tauri updater plugin polls. With `releaseDraft: true`, every automated CI build produced a draft that silently broke OTA until a maintainer manually published it.

### Task 2: S7 — Atomic Window Label Counter

Replaced the wall-clock millisecond window label in `open_new_window` with an `AtomicU64` counter:

- Added `WindowCounter(AtomicU64)` struct to `commands.rs` with `new()` (starts at 1) and `next()` (fetch_add SeqCst)
- Updated `open_new_window` signature to accept `counter: tauri::State<'_, WindowCounter>`
- Window label is now `format!("window-{}", counter.next())` — guaranteed unique across concurrent calls
- Registered `commands::WindowCounter::new()` in `lib.rs` Builder chain via `.manage()`
- `cargo check` passes with 0 errors (2 pre-existing warnings unrelated to this plan)
